# Course data

| File | What | Sources and licences |
| --- | --- | --- |
| `romanby.json` | Romanby Golf Club, all 18 holes | Layout © OpenStreetMap contributors, available under the [Open Database Licence (ODbL)](https://opendatacommons.org/licenses/odbl/); elevation from AWS Terrain Tiles (Mapzen Terrarium); hole 2 ground and splat alignment from a drone flyover reconstruction |
| `st-andrews-old.json` | The Old Course, St Andrews, all 18 holes | Layout © OpenStreetMap contributors (ODbL); elevation from AWS Terrain Tiles |
| `augusta-national.json` | Augusta National Golf Club, all 18 holes | Layout © OpenStreetMap contributors (ODbL); elevation from AWS Terrain Tiles |
| `index.json` | The in-game course list | Generated by `scripts/catalog.ts` |

`romanby.json`, `st-andrews-old.json` and `augusta-national.json` are derivatives of
OpenStreetMap data and are shared under the ODbL. The game
shows the attribution on screen. Rebuild it with:

```bash
npx tsx scripts/bake-course.ts romanby-osm.json romanby-base.json
npx tsx scripts/attach-splat.ts romanby-base.json public/courses/romanby-h2.json 2 public/courses/romanby.json
```

The Old Course and Augusta files were baked with `--course "Old Course"` and
`--course "Augusta National"`, which separate them from the neighbouring courses (the other
St Andrews links, Augusta Country Club, and Augusta's par-3 course).

These files come from the BackyardGolf project, which baked them with the same scripts that are in
`scripts/` here. The photoreal splat capture of Romanby hole 2 is not included; Greenside Classic draws
every hole, including that one, in its own style.
